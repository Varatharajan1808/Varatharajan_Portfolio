## 🚀 Overview

This repository hosts the personal portfolio of **T Varatharajan**, a 3D Engine Developer based in Chennai, India. The application features a custom, high-performance **Three.js 3D background canvas** with a dynamic perspective CAD ground grid, mouse-parallax camera orbiting, floating wireframe polyhedra, and an interactive screenshot gallery and lightbox inspector.

### Key Architectural Features:
- **Interactive 3D Canvas:** Lightweight, 60 FPS Three.js background with dynamic perspective CAD plane and mouse-reactive parallax.
- **Interactive Engine Showcase:** Multi-view screenshot carousel and high-resolution Lightbox modal for inspecting real 3D engine interfaces (scene graphs, material editors, gizmos, and vehicle CAD meshes).
- **Video Demonstration Player:** Integrated inline and modal video playback for live engine and shader demonstrations.
- **ScrollSpy Navigation:** Real-time section tracking highlighting the active viewport section in the navigation bar.
- **Zero-Bloat Performance:** Sub-second production build (~750ms), 100% responsive, optimized for both desktop and mobile devices.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Varatharajan1808/Varatharajan_Portfolio.git

# Navigate to project directory
cd Varatharajan_Portfolio

# Switch to the portfolio branch
git checkout portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production

```bash
# Type-check and build production bundle
npm run build

# Run linter
npm run lint
```
